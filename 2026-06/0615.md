## JPA

- Java 객체를 데이터베이스 테이블과 자동으로 연결해주는 기술
- SQL을 내가 직접 많이 쓰지 않아도 객체를 저장하고 조회할 수 있게 해주는 것

## Java 객체 -> JPA -> SQL 자동 생성 -> DB

## JDBC

- 내가 직접 음식 주문하고
- 계산하고
- 설거지까지 다 함

## Mybatis

- 주문은 내가 하지만
- 요리는 셰프가 해줌(SQL은 내가 작성)

## JPA

- 메뉴만 말하면
- 주문, 요리, 계산, 정리, 거의 다 해줌(SQL도 자동 생성)

1. Entity → DB 테이블을 Java 객체로 만든 것.
2. JPA → 객체를 DB와 자동으로 연결하고 SQL을 생성해주는 기술.
3. EntityManager → JPA에게 저장, 조회, 수정, 삭제를 시키는 관리자.
4. Persistence Context → 객체를 잠시 관리하는 메모리 공간(1차 캐시).
5. JPQL → 테이블이 아니라 Entity 객체를 대상으로 조회하는 쿼리.
