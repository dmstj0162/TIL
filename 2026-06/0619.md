## 정책정의서 - Market Data

| 설정                | 정책 내용                                                                                                   |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| Market Data Service | 국내주식·미국주식·홍콩주식·실시간 시세, 보조 시세, 투자정보를 담당한다.                                     |
| 외부 API 연동       | 증권 정보 및 시세 데이터는 프로젝트에서 계약한 외부 Open API를 통해 조회한다.                               |
| 종목 검색           | 사용자는 종목명 또는 종목코드를 입력하여 종목을 검색할 수 있다.                                             |
| 검색어              | 검색어가 정확히 일치할 경우 우선 조회된다.                                                                  |
| 종목 상세정보       | 종목은 StockCode를 기준으로 조회한다.                                                                       |
| 검색 결과           | 검색 결과는 종목코드, 종목명, 시장(KOSPI, KOSDAQ), 현재가, 등락률을 제공한다.                               |
| 관심 종목           | 관심 종목 데이터는 사용자의 개별 계정 단위에서 서버에 저장 및 관리한다.                                     |
| 종목·관심 조회      | DB에 저장된 종목 목록을 조회할 수 있다.                                                                     |
| 실시간 시세 조회    | 사용자가 요청한 종목의 실시간 시세 정보를 조회한다.                                                         |
| 시세 데이터 제공    | 실시간 시세, 호가, 체결가 등의 정보를 TransStock에서 제공한다.                                              |
| 최신 시세 저장      | 프로그램은 주기적으로 최신 시세를 DB에 저장하며 조회 시 최신 데이터를 우선 사용한다.                        |
| API 호출            | 사용자가 종목 상세 또는 최신 조회를 요청하면 외부 API를 호출한다.                                           |
| API 호출 실패       | 외부 API 호출 실패 시 오류 원인을 반환하고 관리자 로그를 남긴다.                                            |
| API 호출 제한       | 외부 API 호출 제한 정책을 준수하며 호출 횟수를 관리한다.                                                    |
| 보안 정책           | API Key와 Secret은 환경변수 또는 Secret Manager를 통해 관리하며 코드에 직접 작성하지 않는다.                |
| 조회 대상           | KOSPI 및 KOSDAQ 상장 종목을 조회할 수 있으며, 해외시장 종목 및 신용시장 정보는 조회 대상이 아니다.          |
| 종목 정보 저장      | 종목코드, 종목명, 시장코드 등 기본 정보를 DB에 저장하여 관리한다.                                           |
| 인증 방식           | 증권회사 API 호출은 인증 방식으로 수행한다.                                                                 |
| 로그인              | API 호출을 위해 발급받은 Access Token을 이용하여 API Key로 인증 절차를 진행한다.                            |
| 검색 결과 개수      | 검색 결과는 최대 20건까지 반환한다.                                                                         |
| 관심 시세 조회      | 사용자의 관심종목에 저장된 종목의 실시간 시세 정보를 조회할 수 있다.                                        |
| 관심 시세 기준      | 외부 API에서 제공하는 시세 데이터를 기준으로 조회한다.                                                      |
| 관심 시세 저장      | 관심 시세 데이터는 외부 API 응답 데이터(RealtimeData)를 DB에 저장한다.                                      |
| 조회 가능 기간      | 저장된 시세 데이터를 이용하여 기간별 조회가 가능하다.                                                       |
| 조회 가능 시간      | 요청한 날짜의 시세 데이터가 없으면 조회가 불가능하다.                                                       |
| 종목 가격           | 최신가를 기준으로 표시한다.                                                                                 |
| 시세 동기화         | 최신 시세 및 뉴스 시세는 외부 Open API 기준으로 주기적으로 동기화된다.                                      |
| 데이터 정합성       | 동일한 종목의 동일한 시세 데이터는 중복 저장하지 않는다.                                                    |
| 포트폴리오          | 프로젝트에서 생성 및 관리하는 포트폴리오는 사용자 단위로 분리 저장된다.                                     |
| 데이터 수정 방식    | 종목 정보와 시세 데이터는 최신 시세만 수정하고, 요청 정보는 정적인 데이터로 관리 및 생산한다.               |
| Fallback 처리       | 요청한 시세 데이터가 DB에 없는 경우 외부 Open API를 호출하여 데이터를 조회하고, 조회 성공 시 DB에 저장한다. |
| Fallback 실패       | 외부 API 호출에도 실패한 경우 조회 실패를 반환하며 원인 메시지와 로그를 함께 기록한다.                      |
| 생성 정책           | 조회 기록이 존재하지 않는 종목 조회가 필요한 경우 새로운 종목을 생성할 수 있다.                             |
