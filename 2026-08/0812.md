8.  AWS 통합 배포 아키텍처 구축 가이드
    목표 구조
    사용자 요청을 안전하게 받아 프론트엔드와 백엔드를 제공하고, 백엔드
    서버와 DB는 필요에 따라 외부 직접 노출을 최소화한다.

예시 아키텍처
Internet
│
├─ React 정적 서비스(S3/CloudFront)
│
└─ HTTPS
│
ALB (Public Subnet)
│
Spring Boot (Private Subnet)
│
Database (Private Subnet)

관리자 → Bastion(Public Subnet) → Private Server
Private Server → NAT Gateway → Internet

VPC와 CIDR 생성

Public/Private Subnet 구성

Internet Gateway 연결

NAT Gateway 구성

Public/Private Route Table 연결

Security Group 설계

Bastion 및 애플리케이션 서버 구성

ALB와 Target Group 연결

ACM 인증서로 HTTPS 적용

React/Spring Boot 배포 및 통신 확인

보안 체크
IAM 최소 권한 적용

DB를 외부에 직접 공개하지 않기

SSH 접근 범위 제한

비밀키/DB 비밀번호를 Git에 커밋하지 않기

HTTPS 적용

장애 확인 순서
Security Group

Route Table

Subnet/Public IP 여부

ALB Target Health

애플리케이션 포트와 실행 상태

환경변수와 DB 연결

애플리케이션 로그

전체 핵심
VPC가 네트워크의 기반이고, Subnet과 Route Table이 경로를 나누며,
NAT/IGW가 인터넷 연결을 담당한다. ALB는 외부 요청을 분산하고 HTTPS를
적용하며, IAM은 AWS 리소스 접근 권한을 제어한다.
