7.  React와 Spring Boot 배포
    기본 구조
    프론트엔드 React와 백엔드 Spring Boot를 각각 빌드한 뒤 AWS 환경에
    배포한다.

React
Vite 기반 프로젝트라면 일반적으로 다음 과정으로 정적 파일을 생성한다.

npm install
npm run build
생성된 정적 파일은 S3 + CloudFront 등의 구성으로 서비스할 수 있다.

Spring Boot
Gradle 프로젝트 예시:

./gradlew clean build
java -jar build/libs/\*.jar
EC2 또는 Elastic Beanstalk 등에 배포할 수 있다.

배포 시 확인할 항목
운영 환경변수/API URL

DB 접속 정보

CORS 설정

Security/JWT 설정

보안 그룹 포트

HTTPS 적용

로그 확인

프론트-백엔드 연결
브라우저 → React → HTTPS API 요청 → ALB → Spring Boot → DB 형태로 구성할
수 있다.
