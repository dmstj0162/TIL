3.  MobaXterm과 Bastion Server
    MobaXterm
    Windows에서 SSH 접속과 터미널 작업을 편리하게 수행할 수 있는 도구다. AWS
    EC2 Linux 서버 접속 시 사용할 수 있다.

SSH 접속 기본
서버의 Public IP 또는 DNS 확인

SSH 포트(기본 22) 접근 허용 확인

EC2 생성 시 발급한 키 페어 사용

사용자 이름은 AMI 종류에 따라 다를 수 있음

Bastion Server란?
외부 인터넷에서 Private Subnet의 서버로 직접 접속하지 않고, 중간 접속
지점 역할을 하는 서버다. Jump Host라고도 한다.

접속 구조
내 PC → Bastion Server(Public Subnet) → 내부 서버(Private Subnet)

사용하는 이유
내부 서버를 인터넷에 직접 노출하지 않음

관리용 접속 경로를 제한할 수 있음

보안 그룹으로 SSH 접근 범위를 통제하기 쉬움

주의사항
Bastion의 SSH 포트를 모든 IP에 개방하기보다 관리자 IP 등 필요한 범위로
제한하는 것이 좋다.
