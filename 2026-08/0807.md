5.  NAT Gateway와 Route Table
    NAT Gateway
    Private Subnet의 인스턴스가 외부 인터넷으로 요청을 보낼 수 있도록
    지원하는 관리형 NAT 서비스다. 외부에서 Private 인스턴스로 직접 접속하는
    용도로 사용하는 것은 아니다.

일반적인 구성
Private EC2 → Private Route Table → NAT Gateway → Internet Gateway →
Internet

NAT Gateway는 일반적으로 Public Subnet에 생성하고 Elastic IP를 연결한다.

Route Table
서브넷의 네트워크 트래픽이 어디로 이동할지 결정하는 라우팅 규칙
모음이다.

Public Route Table 예
VPC 내부 대역 → local

0.0.0.0/0 → Internet Gateway

Private Route Table 예
VPC 내부 대역 → local

0.0.0.0/0 → NAT Gateway

핵심 정리
Internet Gateway: 인터넷과 VPC 연결

NAT Gateway: Private 자원의 외부 방향 인터넷 통신 지원

Route Table: 실제 트래픽 경로 결정
