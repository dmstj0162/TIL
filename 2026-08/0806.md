4.  VPC와 Subnet
    VPC
    Virtual Private Cloud의 약자로 AWS 내부에 만드는 논리적으로 격리된 가상
    네트워크다.

VPC 구성 요소
CIDR: VPC가 사용할 IP 주소 범위

Subnet: VPC 네트워크를 더 작은 범위로 분리

Internet Gateway: VPC와 인터넷 연결

Route Table: 네트워크 트래픽 경로 결정

NAT Gateway: Private Subnet의 외부 통신 지원

Public Subnet
인터넷 게이트웨이로 향하는 라우팅이 설정된 서브넷이다. 일반적으로 외부에
공개되어야 하는 Load Balancer나 Bastion 등을 배치한다.

Private Subnet
인터넷 게이트웨이로 직접 나가는 경로가 없는 서브넷이다. 애플리케이션
서버나 DB처럼 외부 직접 노출을 피해야 하는 자원을 배치할 수 있다.

예시
VPC: 10.0.0.0/16 - Public Subnet: 10.0.1.0/24 - Private Subnet:
10.0.2.0/24

핵심
Subnet이 Public/Private인지 여부는 이름이 아니라 Route Table의 라우팅
구성에 의해 결정된다.
