6.  Application Load Balancer와 HTTPS 설정
    Application Load Balancer(ALB)
    HTTP/HTTPS 요청을 여러 대상 서버로 분산하는 Layer 7 로드밸런서다.

주요 구성 요소
Load Balancer: 외부 요청을 받음

Listener: 특정 포트/프로토콜의 요청 감지

Target Group: 요청을 전달할 서버 그룹

Health Check: 대상 서버의 정상 여부 확인

요청 흐름
사용자 → ALB → Target Group → EC2/Spring Boot

HTTPS
HTTP 통신에 TLS 암호화를 적용한 방식이다. 로그인 정보나 토큰 등 네트워크
데이터 보호에 중요하다.

AWS HTTPS 구성 예
도메인 준비

AWS Certificate Manager(ACM)에서 인증서 발급

ALB에 HTTPS 443 Listener 추가

ACM 인증서 연결

Target Group으로 요청 전달

필요하면 HTTP 80 요청을 HTTPS 443으로 Redirect

핵심
ALB가 외부 HTTPS 연결을 종료하고 내부 애플리케이션으로 트래픽을 전달하는
구조를 많이 사용한다.
