# 1. RAID (Redundant Array of Independent Disks)

여러 개의 디스크를 하나처럼 사용하여 성능 향상 및 데이터 안정성을 높이는 기술

| RAID   | 핵심                                     |
| ------ | ---------------------------------------- |
| RAID 0 | Striping, 속도 향상, 장애 복구 불가      |
| RAID 1 | Mirroring, 동일 데이터 저장, 안정성 향상 |
| RAID 2 | 해밍 코드(Hamming Code) 사용             |
| RAID 3 | 바이트 단위 저장 + 패리티 디스크         |
| RAID 4 | 블록 단위 저장 + 패리티 디스크           |
| RAID 5 | 블록 단위 저장 + **분산 패리티**         |
| RAID 6 | 블록 단위 저장 + **이중 패리티(2개)**    |

### 암기

- RAID 0 : 속도
- RAID 1 : 미러링
- RAID 5 : 분산 패리티
- RAID 6 : 이중 패리티

# 2. 트랜잭션 및 회복(Recovery)

| 용어       | 핵심                             |
| ---------- | -------------------------------- |
| COMMIT     | 트랜잭션 결과를 영구 저장        |
| ROLLBACK   | 작업을 이전 상태로 되돌림        |
| UNDO       | 커밋되지 않은 작업 취소          |
| REDO       | 커밋된 작업 다시 수행            |
| LOG        | 데이터 변경 내역을 기록          |
| RECOVERY   | 장애 발생 후 정상 상태로 복구    |
| BACKUP     | 장애에 대비하여 데이터 백업      |
| CHECKPOINT | 복구 시작 기준점, 복구 시간 단축 |

## 암기

- COMMIT → 저장
- ROLLBACK → 취소
- UNDO → 커밋 X → 취소
- REDO → 커밋 O → 다시 수행

# 3. 이상(Anomaly)

데이터 중복으로 인해 삽입, 삭제, 갱신 시 발생하는 문제

### 삽입 이상 (Insertion Anomaly)

> 테이블에 데이터를 삽입할 때 의도와 상관없는 값들도 함께 삽입해야 하는 현상이다.

### 삭제 이상 (Deletion Anomaly)

> 테이블에서 튜플을 삭제할 때 의도와 상관없는 값들도 함께 삭제되는 현상이다.

### 갱신 이상 (Update Anomaly)

> 테이블에서 튜플을 갱신할 때 일부 정보만 갱신되어 데이터의 불일치가 발생하는 현상이다.

## 암기

- 삽입 → 원하지 않는 값도 함께 삽입
- 삭제 → 원하지 않는 값도 함께 삭제
- 갱신 → 일부만 수정되어 데이터 불일치

# 4. Python 함수

| 함수      | 기능                                 |
| --------- | ------------------------------------ |
| pop()     | 마지막 요소 삭제 후 반환             |
| push()    | 스택에 데이터 삽입 _(자료구조 개념)_ |
| reverse() | 리스트 순서 뒤집기                   |
| index()   | 값의 위치(인덱스) 반환               |
| write()   | 파일에 데이터 기록                   |
| sort()    | 리스트 정렬                          |
| extend()  | 여러 요소를 한 번에 추가             |
| copy()    | 리스트 복사                          |

## 암기

- pop → 꺼내기
- push → 넣기
- reverse → 뒤집기
- index → 위치 찾기
- write → 파일 쓰기
- sort → 정렬
- extend → 여러 개 추가
- copy → 복사
