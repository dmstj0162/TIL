# 1. LangSmith란?

LangSmith는 LLM 애플리케이션의 개발, 디버깅, 평가를 위한 플랫폼이다.

주요 기능

- Trace 확인
- 실행 시간 측정
- 입력/출력 확인
- Token 사용량 확인
- 오류 분석
- Dataset 평가
- Experiment 비교

---

# 2. LangSmith 환경 설정

필요 패키지

```bash
pip install langsmith
pip install python-dotenv
```

환경 변수(.env)

```text
LANGSMITH_API_KEY=...
LANGSMITH_TRACING=true
LANGSMITH_ENDPOINT=https://api.smith.langchain.com
LANGSMITH_PROJECT=프로젝트명

OPENAI_API_KEY=...
```

---

# 3. Workflow Trace

실행 과정

```
사용자 입력
      │
      ▼
Workflow 시작
      │
      ▼
Prompt 생성
      │
      ▼
LLM 호출
      │
      ▼
응답 생성
      │
      ▼
Trace 저장
```

확인 가능한 정보

- 실행 시간
- 입력값
- 출력값
- Prompt
- Model
- Token 사용량
- 오류 여부

---

# 4. Trace를 사용하는 이유

기존에는

- print()
- logging

등으로 확인해야 했다.

LangSmith에서는

- 전체 실행 흐름
- 함수 호출
- Prompt
- 응답
- 에러 위치

를 한 화면에서 확인할 수 있다.

---

# 5. 실패 Trace 분석

오류가 발생하면

- 어느 단계에서 실패했는지
- 어떤 입력이 들어왔는지
- 어떤 Prompt였는지
- 예외가 발생한 위치

를 쉽게 확인할 수 있다.

장점

- 디버깅 시간 단축
- 문제 원인 파악 용이

---

# 6. Debug & Fix

오류를 수정한 후

- 다시 실행
- 새로운 Trace 생성
- 이전 Trace와 비교

를 수행한다.

확인 항목

- 오류 해결 여부
- 응답 변화
- 실행 시간 변화

---

# 7. Dataset Evaluation

여러 입력 데이터를 준비하여

LLM 성능을 자동 평가한다.

예시

```
질문1
질문2
질문3
...
```

평가 항목

- 정확도
- 일관성
- 응답 품질

장점

- 반복 테스트 자동화
- 성능 비교 가능

---

# 8. Experiment 비교

동일한 Dataset을

- Prompt A
- Prompt B

또는

- Model A
- Model B

에 실행하여 결과를 비교한다.

비교 항목

- 응답 품질
- 정확도
- Token 사용량
- 비용
- 실행 시간

# 느낀 점

Trace를 통해 LLM 내부 실행 과정을 시각적으로 확인할 수 있어 디버깅이 훨씬 쉬워졌다. 특히 Prompt와 응답을 함께 확인할 수 있어 문제 원인을 빠르게 파악할 수 있었다.
