# 12_AI 수업 정리 (03_GPT + 04_LangChain)

## 1. GPT 기초 (03_GPT)

### Token / Embedding / Attention

- Token: LLM이 처리하는 최소 단위
- Embedding: 텍스트를 의미를 가진 벡터로 변환
- Attention: 입력 문맥에서 중요한 정보를 선택하여 반영
- Transformer 기반 동작 원리 이해

### Prompt Engineering

#### Prompt Builder

- 역할(Role), 목표(Task), 입력(Input), 출력(Output) 설계
- 변수 기반 프롬프트 작성

#### Few-shot Prompting

- 예시를 제공하여 원하는 출력 형식 유도
- Zero-shot / One-shot / Few-shot 비교

#### Delimiter Prompting

- \`\`\`, ###, XML, JSON 등의 구분자를 이용해 입력을 명확히 구분

#### Structured Output

- JSON 형식의 응답 생성
- 프로그램에서 후처리하기 쉬운 구조

#### Chain of Thought(CoT)

- 단계별 추론을 유도하여 복잡한 문제 해결 정확도 향상

### Tools / Function Calling

- 함수(Function) 스키마 정의
- LLM이 적절한 함수 선택
- 함수 실행 결과를 다시 모델에 전달
- OpenAI Function Calling API 사용

### Fine-tuning

- Fine-tuning Job 생성
- JSONL 데이터셋 구성
- Prompt / Completion 형식 학습 데이터 작성

## 2. LangChain (04_langchain)

### PromptTemplate

- PromptTemplate
- ChatPromptTemplate
- 변수 치환
- system / user 메시지 구성
- invoke()를 이용한 프롬프트 생성

### Runnable Chain (LCEL)

- PromptTemplate → ChatOpenAI → OutputParser 연결
- Runnable 인터페이스
- invoke() 실행 흐름

### Output Parser

- JsonOutputParser
- Pydantic(BaseModel, Field)
- format_instructions 활용
- 모델 응답을 객체(JSON)로 변환

### Quiz Generation

- PromptTemplate
- ChatOpenAI
- JsonOutputParser
- 객관식 퀴즈 자동 생성
- 문제, 보기, 정답, 해설을 구조화하여 출력
