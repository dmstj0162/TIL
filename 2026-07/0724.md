1. FastAPI란?

FastAPI는 Python으로 REST API 서버를 만들기 위한 웹 프레임워크이다.

Python의 타입 힌트를 활용하여 다음 기능을 제공한다.

요청 데이터 자동 변환

요청값 유효성 검증

JSON 응답 자동 생성

Swagger API 문서 자동 생성

비동기 처리 지원

Pydantic을 이용한 데이터 모델 정의

FastAPI 애플리케이션은 FastAPI 객체를 생성하면서 시작한다.

from fastapi import FastAPI

app = FastAPI()

4. 경로 동작 함수와 데코레이터

FastAPI에서는 데코레이터를 사용해 URL과 Python 함수를 연결한다.

@app.get("/")
async def root() -> dict[str, str]:
return {"message": "Hello FastAPI"}

위 코드는 다음 요청을 처리한다.

GET /

함수가 Python 딕셔너리를 반환하면 FastAPI가 자동으로 JSON 응답으로 변환한다.

{
"message": "Hello FastAPI"
}

주요 HTTP Method

@app.get("/items")
@app.post("/items")
@app.put("/items/{item_id}")
@app.delete("/items/{item_id}")

Method

일반적인 역할

GET

데이터 조회

POST

데이터 생성

PUT

데이터 전체 수정

PATCH

데이터 일부 수정

DELETE

데이터 삭제

허용되지 않은 HTTP Method로 요청하면 일반적으로 405 Method Not Allowed가 발생한다.

5. 경로 매개변수

URL 경로 중 일부를 변수로 받을 수 있다.

@app.get("/hello/{name}")
async def say_hello(name: str) -> dict[str, str]:
return {"message": f"Hello {name}"}

요청 예시:

GET /hello/eunseo

응답 예시:

{
"message": "Hello eunseo"
}

{name}과 함수 매개변수 name의 이름이 일치해야 한다.

6. Path를 이용한 경로 매개변수 검증

Path를 사용하면 경로 매개변수에 조건을 지정할 수 있다.

from typing import Annotated
from fastapi import Path

@app.get("/items/{item_id}")
async def read_item(
item_id: Annotated[
int,
Path(ge=1, description="1 이상의 item ID")
]
) -> dict[str, int]:
return {"item_id": item_id}

위 코드에서 item_id는 다음 조건을 가진다.

정수여야 함

1 이상이어야 함

Swagger 문서에 설명이 표시됨

자주 사용하는 숫자 검증 옵션

옵션

의미

gt

초과

ge

이상

lt

미만

le

이하

예를 들어 Path(ge=1)은 값이 1 이상이어야 한다는 뜻이다.

7. Enum을 이용한 허용값 제한

URL에서 받을 수 있는 값을 미리 제한할 수 있다.

from enum import StrEnum

class ModelName(StrEnum):
alexnet = "alexnet"
resnet = "resnet"
lenet = "lenet"

@app.get("/models/{model_name}")
async def read_model(model_name: ModelName) -> dict[str, str]:
descriptions = {
ModelName.alexnet: "이미지 분류 모델",
ModelName.resnet: "잔차 연결을 사용하는 이미지 모델",
ModelName.lenet: "초기 합성곱 신경망",
}

    return {
        "model_name": model_name,
        "description": descriptions[model_name],
    }

다음 값만 정상적으로 요청할 수 있다.

alexnet
resnet
lenet

목록에 없는 값이 전달되면 FastAPI가 검증 오류를 반환한다.

8. 경로 선언 순서

고정 경로와 동적 경로가 함께 있을 때 선언 순서가 중요하다.

@app.get("/user/me")
async def read_current_user():
return {"user-id": "me"}

@app.get("/user/{user_id}")
async def read_user(user_id: str):
return {"user-id": user_id}

고정 경로인 /user/me를 동적 경로 /user/{user_id}보다 먼저 선언해야 한다.

그렇지 않으면 "me"가 user_id 값으로 처리될 수 있다.

9. Query Parameter

쿼리 매개변수는 URL의 ? 뒤에 전달되는 값이다.

/items?skip=0&limit=3&category=python

FastAPI에서는 경로에 포함되지 않은 함수 매개변수를 일반적으로 Query Parameter로 처리한다.

@app.get("/items")
async def list_items(
skip: int = 0,
limit: int = 3,
category: str | None = None,
):
...

Query를 이용한 검증

from typing import Annotated
from fastapi import Query

@app.get("/items")
async def list_items(
skip: Annotated[int, Query(ge=0)] = 0,
limit: Annotated[int, Query(ge=1, le=10)] = 3,
category: str | None = None,
):
...

조건은 다음과 같다.

skip: 0 이상

limit: 1 이상 10 이하

category: 생략 가능

기본값과 선택값

skip: int = 0

기본값이 있으므로 요청에서 생략할 수 있다.

category: str | None = None

문자열 또는 None이 가능하므로 선택값이다.

10. 목록 조회와 페이징

저장소에서는 다음과 같이 데이터를 미리 정의한다.

ITEMS = [
ItemResponse(id=1, name="FastAPI 기초", category="python"),
ItemResponse(id=2, name="REST API", category="web"),
ItemResponse(id=3, name="Spring 연동", category="java"),
ItemResponse(id=4, name="파일 API", category="python"),
]

필터링과 페이징은 다음 방식으로 수행한다.

filtered = [
item
for item in ITEMS
if category is None or item.category == category
]

return filtered[skip : skip + limit]

category가 없으면 전체 데이터 사용

category가 있으면 같은 카테고리만 조회

슬라이싱으로 skip, limit 적용

12. Request Body

POST나 PUT 요청에서는 JSON 데이터를 요청 본문으로 전달할 수 있다.

FastAPI에서 BaseModel 타입의 매개변수는 Request Body로 해석된다.

from pydantic import BaseModel, Field

class ItemCreate(BaseModel):
name: str = Field(min_length=1, max_length=50)
description: str | None = None
price: float = Field(gt=0)
tax: float | None = Field(default=None, ge=0)

@app.post("/items")
async def create_item(item: ItemCreate) -> dict:
return item.model_dump()

요청 예시:

{
"name": "FastAPI 교재",
"description": "FastAPI 기초 학습용",
"price": 25000,
"tax": 2500
}

13. Pydantic BaseModel

BaseModel은 요청 또는 응답 데이터의 구조를 정의한다.

class UserInfo(BaseModel):

full_name: str | None = None

Pydantic 모델을 사용하면 다음 작업이 자동으로 처리된다.

JSON을 Python 객체로 변환

값 범위 검증

API 문서 스키마 생성

Pydantic v2에서는 모델 객체를 딕셔너리로 변환할 때 model_dump()를 사용한다.

item = ItemCreate(

item.model_dump()

17. dict와 Pydantic 모델의 차이

저장소의 validation 예제에는 검증 없이 일반 딕셔너리를 받는 API가 있다.

@app.post("/examples/raw")
async def accept_raw_json(payload: dict) -> dict:
return {
"received": payload,
"warning": "내부 필드 검증 없음",
}

dict로 요청을 받으면 JSON 객체 자체인지는 확인할 수 있지만, 내부 필드의 이름이나 타입은 구체적으로 검증하지 않는다.

예를 들어 다음 데이터도 그대로 받을 수 있다.

{
"name": 123,
"price": "무료",
"unknown": true
}

반면 Pydantic 모델을 사용하면 기대하는 필드와 타입을 명확히 지정할 수 있다.

class Product(BaseModel):
name: str
price: float

API의 안정성을 높이기 위해 실제 애플리케이션에서는 단순 dict보다 Pydantic 모델 사용이 권장된다.

현재 저장소의 04_validation/main.py는 dict 요청과 검증 모델을 비교하기 위한 시작 코드만 포함되어 있다.

18. 동기와 비동기

FastAPI에서는 일반 함수와 비동기 함수를 모두 경로 동작 함수로 사용할 수 있다.

동기 함수

import time

@app.get("/wait/sync")
def sync_wait(seconds: float = 1):
time.sleep(seconds)

    return {
        "type": "sync",
        "waited_seconds": seconds,
    }

time.sleep()은 실행 중인 스레드를 멈추는 동기 방식이다.

비동기 함수

import asyncio

@app.get("/wait/async")
async def async_wait(seconds: float = 1):
await asyncio.sleep(seconds)

    return {
        "type": "async",
        "waited_seconds": seconds,
    }

await asyncio.sleep()은 대기 중 다른 비동기 작업이 실행될 수 있도록 제어권을 넘긴다.

구분

형태

사용 예

def

동기 라이브러리, CPU 연산, 동기 I/O

async def

비동기 HTTP 요청, 비동기 DB, 비동기 파일 처리

time.sleep()

동기 대기

await asyncio.sleep()

비동기 대기

단순히 함수 앞에 async를 붙이는 것만으로 내부의 동기 작업이 비동기로 바뀌는 것은 아니다.

19. Annotated

저장소에서는 타입과 검증 설정을 함께 표현하기 위해 Annotated를 사용한다.

from typing import Annotated

item_id: Annotated[int, Path(ge=1)]

구조는 다음과 같다.

Annotated[실제_타입, 추가_정보]

예시:

skip: Annotated[int, Query(ge=0)] = 0

실제 타입: int

추가 검증: Query(ge=0)

기본값: 0

이 방식은 타입 정보와 FastAPI 설정을 구분하기 쉬워진다는 장점이 있다.

22. 오류 처리 흐름

FastAPI는 요청 데이터를 경로 함수에 전달하기 전에 검증한다.

↓
Path / Query / Body 분석
↓
타입 변환 및 Pydantic 검증
↓
검증 성공 → 경로 함수 실행
검증 실패 → 오류 응답 반환

대표적인 상황은 다음과 같다.

상황

결과

요청값 검증 실패

from typing import Annotated

from fastapi import FastAPI, Path, Query
from pydantic import BaseModel, Field

app = FastAPI(title="FastAPI Example")

@app.post("/items/{item_id}")
async def create_or_update_item(

item: ItemCreate,

return {

"item": item.model_dump(),
"notify": notify,
}

25. 이번 실습 핵심 정리

FastAPI() 객체를 생성하여 애플리케이션을 시작한다.

@app.get(), @app.post() 등의 데코레이터로 URL과 함수를 연결한다.

Python 딕셔너리는 JSON 응답으로 자동 변환된다.

{변수명}을 사용하면 Path Parameter를 받을 수 있다.

경로에 없는 단순 매개변수는 Query Parameter로 처리된다.

BaseModel 매개변수는 JSON Request Body로 처리된다.

Path, Query, Field로 요청값 조건을 설정한다.

response_model로 응답 구조를 검증하고 문서화한다.

Annotated로 타입과 검증 정보를 함께 선언할 수 있다.

/docs에서 자동 생성된 Swagger 문서를 확인할 수 있다.

비동기 작업에서는 async def와 await를 사용한다.

내부 필드 검증이 필요하면 일반 dict보다 Pydantic 모델을 사용한다.
