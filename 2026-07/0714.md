# 정보처리기사 실기 학습 정리 (오늘)

## 1. RAID

- RAID 0 : Striping, 속도 향상, 복구 불가
- RAID 1 : Mirroring, 동일 데이터 저장
- RAID 2 : 해밍 코드 사용
- RAID 3 : 바이트 단위 + 패리티
- RAID 4 : 블록 단위 + 패리티
- RAID 5 : 분산 패리티
- RAID 6 : 이중 패리티

## 2. 트랜잭션 및 회복

- COMMIT : 영구 저장
- ROLLBACK : 이전 상태로 되돌림
- UNDO : 커밋되지 않은 작업 취소
- REDO : 커밋된 작업 다시 수행
- LOG : 변경 내역 기록
- RECOVERY : 장애 복구
- BACKUP : 데이터 백업
- CHECKPOINT : 복구 시작 기준점

## 3. 이상(Anomaly)

### 삽입 이상

테이블에 데이터를 삽입할 때 의도와 상관없는 값들도 함께 삽입해야 하는
현상이다.

### 삭제 이상

테이블에서 튜플을 삭제할 때 의도와 상관없는 값들도 함께 삭제되는
현상이다.

### 갱신 이상

테이블에서 튜플를 갱신할 때 일부 정보만 갱신되어 데이터의 불일치가
발생하는 현상이다.

## 4. Python 함수

- pop() : 마지막 요소 삭제 후 반환
- push() : 스택에 데이터 삽입
- reverse() : 순서 뒤집기
- index() : 위치 반환
- write() : 파일 쓰기
- sort() : 정렬
- extend() : 여러 요소 추가
- copy() : 리스트 복사

## 5. 포인터 공식

```c
a == &a[0]
a + i == &a[i]
*(a + i) == a[i]
p = a + i -> *p == a[i]
```

## 6. C 포인터 문제

- a는 배열의 첫 번째 주소
- a+1은 a\[1\]의 주소
- \*p는 p가 가리키는 값
- 최종 출력: 22
