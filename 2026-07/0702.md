## 시세 테이블 생성

```sql
CREATE TABLE ticks (
    id BIGSERIAL,
    stock_code VARCHAR(6) NOT NULL,
    current_price BIGINT NOT NULL,
    price_change BIGINT,
    price_change_rate NUMERIC(6,2),
    price_change_sign VARCHAR(2),
    trading_volume BIGINT,
    ticked_at TIMESTAMPTZ NOT NULL,
    collected_at TIMESTAMPTZ NOT NULL DEFAULT now(),

    PRIMARY KEY (id, ticked_at)
);
```

인덱스

```sql
CREATE INDEX idx_ticks_stock_code_ticked_at
ON ticks(stock_code, ticked_at DESC);
```

Hypertable 생성

```sql
SELECT create_hypertable('ticks', 'ticked_at');
```

# 느낀 점

- Redis Pub/Sub는 데이터를 저장하는 것이 아니라 실시간으로 전달하는 역할이다.
- TimescaleDB는 시계열 데이터를 영구 저장하기 위한 데이터베이스이다.
- WebSocket을 통해 받은 실시간 시세를 저장과 전송으로 분리하여 처리하는 구조를 구현하였다.
