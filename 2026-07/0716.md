# 1. NumPy란?

NumPy(Numerical Python)는 Python에서 수치 계산을 위한 대표적인 라이브러리이다.

### 특징

- 빠른 연산(C 기반)
- 다차원 배열(ndarray) 지원
- 행렬 연산 지원
- AI, 데이터 분석, 머신러닝에서 필수 라이브러리

```python
import numpy as np
```

# 6. NumPy 연산

NumPy는 반복문 없이 배열끼리 연산이 가능하다.

```python
a + b
a - b
a * b
a / b
```

예시

```python
a = np.array([1,2,3])
b = np.array([4,5,6])

print(a+b)
```

결과

```
[5 7 9]
```

# 7. Broadcasting

차원이 달라도 규칙이 맞으면 자동으로 연산된다.

가능한 경우

```
(2,3) + (3,)
```

```
(2,3) + (2,1)
```

불가능한 경우

```
(2,3) + (2,)
```

이유

```
마지막 차원

3 vs 2

같지 않고
둘 중 하나가 1도 아니므로
Broadcast 불가
```

# 11. Cosine Similarity

두 벡터가 얼마나 비슷한지를 계산한다.

공식

```
A·B
-----------------
|A| × |B|
```

결과

- 1 → 완전히 동일
- 0 → 관련 없음
- -1 → 반대 방향

추천 시스템

- 상품 추천
- 문서 검색
- 임베딩 검색

등에서 자주 사용된다.

# 12. GPT의 동작 원리

## Token

문장을 작은 단위로 분리한 것

예시

```
안녕하세요.

↓

["안녕", "하세요", "."]
```

---

## Embedding

토큰을 숫자 벡터로 변환한다.

예시

```
"고양이"

↓

[0.21, -0.84, 0.65, ...]
```

GPT는 문자 자체가 아니라 숫자 벡터를 학습한다.

---

## Query, Key, Value

Attention의 핵심 요소

### Query(Q)

현재 단어가 궁금한 정보

### Key(K)

각 단어의 특징

### Value(V)

실제로 가져올 정보

---

## Attention

관련도를 계산하여 중요한 단어에 높은 가중치를 부여한다.

순서

```
Query

↓

Query × Key

↓

Attention Score

↓

Softmax

↓

Weight

↓

Weight × Value

↓

Context Vector
```

---

## Softmax

점수를 확률 형태로 변환한다.

예시

```
[2, 4, 1]

↓

[0.12, 0.78, 0.10]
```

합은 항상 1이 된다.

---

## Context Vector

Attention 결과로 생성되는 최종 의미 벡터

```
Weights

×

Values

↓

Context
```

GPT는 이 Context를 이용하여 다음 Token을 예측한다.

---

# 오늘 배운 핵심

- NumPy는 AI에서 사용하는 기본 수치 계산 라이브러리이다.
- ndarray는 Python list보다 빠르다.
- Broadcasting은 차원이 맞을 때 자동 연산된다.
- reshape()는 배열 형태를 변경한다.
- Aggregation은 통계값을 계산한다.
- Vector 연산은 AI의 핵심이다.
- Cosine Similarity는 문장 및 벡터의 유사도를 계산한다.
- GPT는 Token → Embedding → Attention → Softmax → Context 과정을 거쳐 다음 단어를 예측한다.
