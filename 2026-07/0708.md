# C언어 포인터 핵심 정리 (정처기 실기용)

> 목표 : C언어를 배우는 것이 아니라 **정처기 포인터 문제를 풀 수 있을 정도만 이해하기**

---

# 1. 포인터 = 주소를 저장하는 변수

```c
int a = 10;
int* p = &a;
```

메모리 모습

```
a
--------
값 : 10

p
--------
값 : a의 주소
```

### & 의 의미

```
&a
```

=

```
a의 주소를 알려줘
```

---

# 2. \* 는 "그 주소 안의 값"

```c
int a = 10;
int* p = &a;
```

여기서

```
p
```

안에는

```
1000
```

같은 주소가 들어있다고 생각하면 된다.

그런데

```
*p
```

라고 쓰면

> "1000번지 안에 있는 값"

을 가져온다.

즉

```
*p = 10
```

### 암기

```
p   → 주소

*p  → 값
```

이거 하나만 기억하면 절반은 끝난다.

---

# 3. p++

Java의

```java
i++;
```

처럼 생각하면 된다.

포인터에서

```c
p++;
```

는

> 다음 칸으로 이동

예를 들어

```
K O R E A
```

가 메모리에 저장되어 있을 때

```
p
↓

K O R E A
```

여기서

```c
p++;
```

하면

```
  p
  ↓
K O R E A
```

즉 **O를 가리킨다.**

또

```c
p++;
```

하면

```
    p
    ↓
K O R E A
```

즉 **R을 가리킨다.**

# 4. \*(p+3)

시험에 가장 많이 나오는 형태

```
K O R E A
```

```
p
↓

K O R E A
```

```
p+1
```

↓

```
O
```

```
p+2
```

p+3

> p+3 위치의 값

# 5. %s 와 %c 차이

```c
printf("%s", p);
```

↓

```
KOREA
```

전체 문자열 출력

반면

```c
printf("%c", *p);
```

↓

```
K
```

문자 하나만 출력

# 7. 배열은 포인터처럼 생각하면 된다.

```c
int a[3];
```

사실은

```
a

↓

[0][1][2]
```

를 의미한다.

그래서

```c
a[0]
```

=

```c
*(a+0)
```

```c
a[1]
```

=

```c
*(a+1)
```

```c
a[2]
```

=

```c
*(a+2)
```

# 정처기에서 가장 많이 나오는 공식

| 코드     | 의미           |
| -------- | -------------- |
| `&a`     | a의 주소       |
| `p`      | 주소           |
| `*p`     | 주소 안의 값   |
| `p+1`    | 다음 칸        |
| `*(p+1)` | 다음 칸의 값   |
| `a[1]`   | `*(a+1)`       |
| `%s`     | 문자열 출력    |
| `%c`     | 문자 하나 출력 |

---

# 시험장에서 기억할 한 줄

```
&  → 주소

*  → 값

+1 → 다음 칸

%s → 끝까지 출력

%c → 한 글자 출력
```

이 다섯 가지만 기억해도 정처기 포인터 문제 대부분을 풀 수 있다.
