# 2026-07-01 작업 내용

## 📌 구현 내용

### 1. 키움 Open API 연동

- Access Token을 발급받아 종목 정보 조회 API를 호출하도록 구현
- `WebClient`를 이용하여 키움 Open API와 통신

### 2. 종목 조회 기능 구현

- 종목 코드를 입력받아 종목 기본 정보를 조회하는 기능 구현
- API 호출 결과를 DTO로 매핑하도록 구성

### 3. DTO 작성

- `KiwoomStockRequest`
  - 종목 조회 요청 DTO 작성
- `KiwoomStockResponse`
  - 종목 조회 응답 DTO 작성

### 4. Market Client 구현

- `KiwoomMarketClient` 작성
- 종목 조회 API 호출 로직 구현
- Access Token을 포함하여 요청하도록 설정

### 5. API 테스트

- Postman을 이용하여 종목 조회 API 테스트
- 삼성전자(005930) 조회 정상 동작 확인
