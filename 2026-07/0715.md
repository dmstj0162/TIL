# 1. datetime

날짜와 시간을 다루기 위한 모듈

```python
from datetime import datetime

now = datetime.now()
print(now)
```

## 현재 날짜/시간 가져오기

```python
today = datetime.today()
now = datetime.now()
```

## 날짜 정보

```python
print(now.year)
print(now.month)
print(now.day)
```

## 시간 정보

```python
print(now.hour)
print(now.minute)
print(now.second)
```

## 날짜와 시간 분리

```python
print(now.date())
print(now.time())
```

# 2. 객체지향(OOP)

객체(Object)를 중심으로 프로그램을 작성하는 방식

## 클래스 생성

```python
class User:

    def __init__(self, name):
        self.name = name
```

## 객체 생성

```python
user = User("홍길동")
```

## 메서드

```python
class User:

    def hello(self):
        print("안녕하세요.")
```

호출

```python
user.hello()
```

# 3. 캡슐화(Encapsulation)

객체 내부 데이터를 외부에서 직접 수정하지 못하도록 보호하는 기법

## private 변수

```python
self.__name
```

앞에

```python
__
```

를 붙이면 외부 접근이 제한된다.

### Getter

```python
@property
def name(self):
    return self.__name
```

### Setter

```python
@name.setter
def name(self, value):
    self.__name = value
```

사용

```python
user.name = "이순신"
print(user.name)
```

# 6. 파일 입출력(IO)

## 파일 열기

```python
file = open("sample.txt")
```

### 읽기

```python
file.read()
```

### 한 줄씩

```python
file.readline()
```

### 여러 줄

```python
file.readlines()
```

### 쓰기

```python
file.write()
```

### 파일 닫기

```python
file.close()
```

### 권장 방법

```python
with open("sample.txt") as file:
    print(file.read())
```

# 7. 예외 처리(Exception)

프로그램 실행 중 발생하는 오류 처리

```

```

```python

```

# Python 접근 제어 정리

| 표현     | 의미                   |
| -------- | ---------------------- |
| name     | public                 |
| \_name   | protected(관례)        |
| \_\_name | private(Name Mangling) |

# 오늘 배운 핵심

- datetime으로 현재 날짜와 시간을 가져올 수 있다.
- 클래스는 객체를 만들기 위한 설계도이다.
- 캡슐화는 데이터를 보호하기 위한 객체지향 기법이다.
- @property를 이용하면 속성처럼 접근할 수 있다.
- 모듈을 이용해 코드를 분리할 수 있다.
- os 모듈로 운영체제와 상호작용할 수 있다.
- 파일은 with open()을 사용하는 것이 안전하다.
- try-except로 예외를 처리한다.
- NumPy는 리스트보다 빠른 수치 계산이 가능하다.
- NumPy의 2차원 배열은 모든 행의 길이가 같아야 한다.
