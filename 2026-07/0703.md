# 2026-07-03 - Stock Ranking Cache 구현

## 📌 작업 목표

사용자에게 종목을 단순 종목코드 순이 아닌 일정한 기준(급등/급락 등)으로 제공하기 위한 랭킹 기능 구현

---

# 구현 내용

## 1. ranking 패키지 생성

기존 market-service에 ranking 도메인을 추가하여 랭킹 기능을 독립적으로 관리하도록 구성

구조

```text
ranking
├── client
├── constant
├── dto
│   ├── cache
│   ├── request
│   └── response
├── exception
├── scheduler
└── service
```

---

## 2. 키움 Open API 연동

가격급등락(ka10019) API를 이용하여

- 급등 종목 조회
- 급락 종목 조회

기능 구현

### Client

- KiwoomRankingClient 생성
- WebClient를 이용한 API 호출
- 응답 DTO 매핑

---

## 3. DTO 작성

### Response DTO

- KiwoomPriceRankResponse
- KiwoomPriceRankItem

### Cache DTO

Redis 저장용 DTO 생성

```text
StockRankingCacheItem
```

저장 정보

- 순위
- 종목코드
- 종목명
- 현재가
- 전일대비
- 등락률
- 거래량
- 상승/하락 부호(priceChangeSign)

---

## 4. Redis 캐싱

StockRankingService 구현

기능

- 급등 조회
- 급락 조회
- 응답 검증
- DTO 변환
- Redis 저장

Redis Key

```text
market:stock-ranking:rising
market:stock-ranking:falling
```

TTL

- 2분

---

## 5. Scheduler 구현

StockRankingScheduler 생성

1분마다

- 급등 랭킹 갱신
- 급락 랭킹 갱신

하도록 구현

---
