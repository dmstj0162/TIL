## 6. Redis 최종 확인

확인 명령어

```redis
KEYS market:stock-ranking:*
TYPE market:stock-ranking:rate-up
TTL market:stock-ranking:rate-up

TYPE market:stock-ranking:rate-down
TTL market:stock-ranking:rate-down
```

확인 결과

- Rising 저장 완료
- Falling 저장 완료
- Volume Spike 저장 완료
- Popular 저장 완료
- Rate Up 저장 완료
- Rate Down 저장 완료
- TTL 정상 적용 확인
