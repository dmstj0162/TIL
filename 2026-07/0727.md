Day 1 - LangGraph 기초

1. Chain vs Graph (01_chain_vs_graph.py)

Chain

순차 실행

흐름이 고정

분기 처리 어려움

<!-- -->

A -> B -> C

Graph

노드(Node)와 엣지(Edge) 기반

조건 분기 가능

반복 및 순환 가능

<!-- -->

A
├── B
└── C
└── D

사용 시점

단순 LLM 호출 → Chain

Agent, Workflow → Graph

2. State / Node / Edge (02_state_node_edge.py)

State

예)

Edge

↓
Node1

END
