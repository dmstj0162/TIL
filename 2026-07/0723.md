7. VectorStore 정리

1. 학습 목표

이번 수업에서는 다음 흐름을 학습했다.

문장을 Embedding Vector로 변환한다.

질문과 문서 Vector의 유사도를 계산한다.

VectorStore에 문서와 Vector를 함께 저장한다.

유사도 검색과 Metadata Filter를 사용한다.

VectorStore를 Retriever로 변환한다.

검색 결과가 올바른지 평가한다.

2. 전체 흐름

원본 문서
↓
Embedding 모델
↓
문서 Vector 생성
↓
VectorStore 저장
↓
사용자 질문 입력
↓
질문 Vector 생성
↓
유사도 검색
↓
관련 문서 반환
↓
LLM Context로 전달

VectorStore는 RAG에서 사용자의 질문과 의미가 비슷한 문서를 찾아주는 역할을 한다.

3. Embedding

Embedding은 문장이나 단어를 컴퓨터가 비교할 수 있는 숫자 배열인 Vector로 변환하는 과정이다.

"강의를 취소하면 환불받을 수 있나요?"
↓ Embedding
[0.021, -0.184, 0.337, ...]

표현이 달라도 의미가 비슷하면 Vector의 방향도 비슷하게 만들어진다.

문서와 질문 변환

document_vectors = embeddings.embed_documents(DOCUMENTS)
question_vector = embeddings.embed_query(QUESTION)

embed_documents(): 여러 문서를 Vector로 변환

embed_query(): 검색 질문 하나를 Vector로 변환

문서와 질문은 반드시 같은 Embedding 모델로 변환해야 한다.

4. Cosine Similarity

Cosine Similarity는 두 Vector가 얼마나 같은 방향을 향하는지 계산한다.

1에 가까움 → 매우 유사
0에 가까움 → 관련성이 낮음
-1에 가까움 → 반대 방향

실습 코드:

def cosine_similarity(
vector_a: list[float],
vector_b: list[float]
) -> float:
dot = sum(a _ b for a, b in zip(vector_a, vector_b))
norm_a = math.sqrt(sum(value _ value for value in vector_a))
norm_b = math.sqrt(sum(value _ value for value in vector_b))
return dot / (norm_a _ norm_b)

각 문서와 질문의 유사도를 계산한 뒤 점수가 높은 순서로 정렬한다.

scored_documents = []

for text, vector in zip(DOCUMENTS, document_vectors):
score = cosine_similarity(question_vector, vector)
scored_documents.append((score, text))

sorted_results = sorted(scored_documents, reverse=True)

VectorStore를 사용하지 않으면 개발자가 문서 Vector 생성, 원문 연결, 전체 비교, 정렬, 상위 결과 선택을 모두 직접 처리해야 한다.

5. VectorStore

VectorStore는 다음 데이터를 함께 저장하고 검색하는 저장소다.

문서 원문

Embedding Vector

문서 ID

Metadata

VectorStore
├─ Document 원문
├─ Embedding Vector
├─ ID
└─ Metadata

VectorStore를 사용하면 Embedding 호출, 문서와 Vector 연결, 저장, 유사도 검색, Filter, 상위 결과 반환을 묶어서 처리할 수 있다.

6. LangChain Document

from langchain_core.documents import Document

document = Document(
id="policy-refund",
page_content="수업 시작 24시간 전까지 취소하면 전액 환불됩니다.",
metadata={
"source": "center_policy.txt",
"topic": "policy"
}
)

주요 속성

id: 문서를 구분하는 고유 식별자

page_content: 검색 대상이 되는 실제 내용

metadata: 출처, 주제 등 부가 정보

Metadata는 출처 표시와 검색 범위 제한에 사용할 수 있다.

7. InMemoryVectorStore

from langchain_core.vectorstores import InMemoryVectorStore

store = InMemoryVectorStore(create_embeddings())

특징:

별도 서버가 필요 없다.

설정이 간단하다.

실습과 테스트에 적합하다.

프로그램이 종료되면 데이터가 사라진다.

대용량 운영 환경에는 적합하지 않다.

8. 문서 저장

stored_ids = store.add_documents(
DOCUMENTS,
ids=[str(document.id) for document in DOCUMENTS]
)

저장 과정:

page_content를 Embedding Vector로 변환

Vector와 Document 연결

ID와 Metadata 함께 저장

반환값은 저장된 문서 ID 목록이다.

9. 유사도 검색

results = store.similarity_search_with_score(
question,
k=3
)

question: 검색 질문

k: 반환할 상위 문서 개수

filter: 선택적으로 적용할 Filter

반환 형태:

[
(Document(...), score),
(Document(...), score)
]

검색 점수의 의미는 VectorStore 구현에 따라 다를 수 있다. 어떤 구현은 값이 클수록 유사하고, 어떤 구현은 거리값을 반환해 작을수록 가까울 수 있다.

10. Top-K

Top-K는 검색 결과 중 상위 몇 개의 문서를 반환할지 결정하는 값이다.

store.similarity_search_with_score(question, k=3)

K가 작은 경우

관련성이 높은 문서만 반환

불필요한 Context 감소

정답 문서를 놓칠 수 있음

K가 큰 경우

필요한 문서를 포함할 가능성 증가

관련 없는 문서도 반환될 수 있음

LLM에 전달되는 Token 증가

11. Metadata Filter

def make_filter(topic: str | None):
if topic is None:
return None

    return lambda document: (
        document.metadata.get("topic") == topic
    )

검색 시 적용:

results = store.similarity_search_with_score(
question,
k=top_k,
filter=make_filter(topic)
)

topic="memory"라면 memory 주제의 문서만 검색한다.

13. Retriever

Retriever는 질문을 입력받아 관련 문서를 반환하는 검색 인터페이스다.

VectorStore
↓
Retriever
├─ 검색 방식
├─ Top-K
└─ Metadata Filter

retriever = store.as_retriever(
search_type="similarity",
search_kwargs={
"k": top_k
}
)

검색:

documents = retriever.invoke(question)

반환값은 Document 목록이다.

[
Document(...),
Document(...)
]

similarity_search_with_score()와 달리 기본적으로 점수는 포함하지 않는다.

Filter 포함 Retriever

memory_retriever = store.as_retriever(
search_kwargs={
"k": 3,
"filter": lambda document:
document.metadata.get("topic") == "memory"
}
)

14. 검색 결과 평가

평가 데이터는 질문과 기대 문구의 쌍으로 구성한다.

EVAL_CASES = [
("외부 자료를 찾아 답변에 사용하는 방법은?", "RAG는"),
("파일이나 웹 페이지를 읽어오는 구성 요소는?", "Loader는"),
("벡터와 원문을 함께 보관하는 검색 저장소는?", "VectorStore는")
]

검색 결과에 기대 문구가 포함되는지 확인한다.

documents = retriever.invoke(question)

matched = any(
expected_text in document.page_content
for document in documents
)

성공 개수 출력:

print(f"검색 성공: {passed}/{len(EVAL_CASES)}")

Metadata Filter 평가:

filtered_docs = memory_retriever.invoke(
"대화를 기억하는 방법은?"
)

filter_passed = bool(filtered_docs) and all(
document.metadata.get("topic") == "memory"
for document in filtered_docs
)

20. 핵심 요약

Embedding은 텍스트를 의미를 담은 숫자 Vector로 변환한다.

문서와 질문은 같은 Embedding 모델을 사용해야 한다.

Cosine Similarity로 두 Vector의 방향 유사도를 비교할 수 있다.

VectorStore는 문서, Vector, ID, Metadata를 함께 관리한다.

similarity_search_with_score()는 관련 문서와 검색 점수를 반환한다.

Top-K는 반환할 상위 검색 결과 개수다.

Metadata Filter로 검색 범위를 제한할 수 있다.

Retriever는 VectorStore 위에 검색 정책을 적용한다.

검색 기능은 정답 문서가 Top-K 안에 포함되는지 평가해야 한다.
