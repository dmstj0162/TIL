2. Memory의 기본 개념

일반적인 LLM은 한 번의 요청만 보면 이전 대화를 자동으로 기억하지 못한다.

따라서 챗봇에서 Memory를 구현하려면 이전 정보를 별도로 저장한 뒤, 새로운 질문을 처리할 때 다시 프롬프트에 포함해야 한다.

이 실습에서는 Memory를 크게 세 부분으로 나눈다.

Profile

사용자에 관한 비교적 오래 유지되는 정보다.

예시:

이름
관심사
목표
학습 수준
선호 설명 방식

Recent Messages

최근 몇 개의 사용자·챗봇 메시지를 보관한다.

현재 질문이 이전 대화와 연결될 때 사용한다.

Summary

전체 대화를 그대로 전달하지 않고, 중요한 내용을 짧게 정리한 정보다.

대화가 길어질수록 전체 메시지를 전달하는 것보다 Summary를 사용하는 편이 효율적이다.

06_session_persistence.py

여러 사용자의 Memory를 세션별로 분리하고 JSON 파일에 저장한다.

MemoryStore 클래스

self.sessions: dict[str, ChatMemory]

session_id를 Key로 사용하여 서로 다른 ChatMemory 객체를 저장한다.

예시:

store.get("student-a")
store.get("student-b")

각 세션은 서로 다른 Profile과 대화 기록을 가진다.

get()

해당 세션이 이미 있으면 기존 Memory를 반환하고, 없으면 새로운 ChatMemory를 생성한다.

save()

모든 세션의 Memory를 Dictionary로 변환한 뒤 JSON 파일에 저장한다.

저장 경로:

runtime/session_memories.json

load()

JSON 파일이 존재하면 파일을 읽어 각 세션의 ChatMemory를 복원한다.

파일이 없으면 빈 MemoryStore를 반환한다.

직렬화와 역직렬화

직렬화

Python 객체를 JSON에 저장 가능한 Dictionary 형태로 변환한다.

memory.to_dict()

역직렬화

Dictionary 데이터를 다시 ChatMemory 객체로 복원한다.

ChatMemory.from_dict(memory_data)

핵심 목적

프로그램이 종료되어도 Memory를 유지하려면 메모리상의 객체만 사용하는 것으로는 부족하다.

파일이나 데이터베이스에 저장하는 Persistence가 필요하다.

6. 주요 오류와 수정 사항

ChatMemory 객체를 Dictionary처럼 접근한 오류

잘못된 코드:

memory["role"]

memory는 ChatMemory 객체이므로 Dictionary 방식으로 접근할 수 없다.

수정:

message["role"]

to_dict() 메서드명 오타

잘못된 코드:

memory.todict()

수정:

memory.to_dict()

get()에서 기존 세션을 반환하지 않는 오류

return이 if문 안에만 있으면 이미 존재하는 세션에서는 None이 반환된다.

수정:

def get(self, session_id: str) -> ChatMemory:
if session_id not in self.sessions:
self.sessions[session_id] = ChatMemory()

    return self.sessions[session_id]

max_tokens 오타

잘못된 코드:

mak_tokens=300

수정:

max_tokens=300

7. 핵심 정리!

LLM 자체가 영구적으로 대화를 기억하는 것은 아니다.

이전 정보를 저장하고 다음 Prompt에 다시 전달해야 Memory처럼 동작한다.

최근 대화는 Window Memory로 관리한다.

장기적으로 필요한 사용자 정보는 Profile에 분리해서 저장한다.

긴 대화는 Summary로 압축하여 Token 사용량을 줄인다.

사용자마다 session_id를 나누어 Memory를 분리해야 한다.

프로그램 종료 후에도 유지하려면 JSON이나 DB에 저장해야 한다.

비밀번호, 주민등록번호, API Key 같은 민감정보는 저장하지 않아야 한다.

사용자가 기억 삭제를 요청할 수 있는 기능도 필요하다.

실제 LLM 프롬프트에는 Profile, Summary, Recent Messages, Current Question을 함께 전달한다.
